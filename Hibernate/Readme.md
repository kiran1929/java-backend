# Hibernate Projects

This directory contains Hibernate ORM practice applications covering basic CRUD operations and entity relationship mapping.

---

## 📁 Modules

| Module | Description | Key Topics |
|---|---|---|
| [**`Hibernet-01`**](Hibernet-01/README.md) | Standard CRUD application with console UI | SessionFactory, Session, Transaction, CRUD operations, HQL queries |
| [**`Many-1-Hibernet`**](Many-1-Hibernet/README.md) | Entity relationship mapping | `@ManyToOne`, `@JoinColumn`, relational persistence, HQL joins |
